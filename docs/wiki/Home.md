A Tkinter Pomodoro timer in Python: Day 28 of Udemy's *100 Days of Code: The Complete Python Pro Bootcamp*. It has no runtime dependencies beyond the Python standard library.

![The Pomodoro timer in a work session](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/028-pomodoro/raw/branch/main/docs/images/screenshot-work.png)

## What it does

The timer follows the Pomodoro technique of Francesco Cirillo: work in focused sessions, rest in between, and take a longer rest after four work sessions. Each finished work session adds a check mark.

| Session | Length | Title | Colour |
| --- | --- | --- | --- |
| Work | 25 minutes | Work | green |
| Short break | 5 minutes | Break | pink |
| Long break (after the fourth work session) | 20 minutes | Break | red |
